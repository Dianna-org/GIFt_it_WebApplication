1. HOW I WORK ON THIS PROJECT (lessons learned)
--------------------------------------------------------------------
- Production build at :3000 has NO dev hooks. A dev server (Vite) can be started in a throw-away container:
      cd frontend && docker run -d --name cs-dev --network msa_webapplication_default -p 3001:3000 \
        -e API_TARGET=http://api:8080 -v "$PWD":/app -w /app node:20-alpine \
        sh -c "npm install --no-audit --no-fund && npx vite --host 0.0.0.0 --port 3000"
  It exposes window.__store (zustand), window.__three (R3F state), window.__tools (tool refs), window.__view
  (camera close-up for checking models). The dev container recently became unreliable (nsfwjs inception model
  resolve errors, navigation failed) – testing on the production build (:3000) with real clicks works fine.
  After using it: docker rm -f cs-dev ; docker run --rm -v "$PWD/frontend":/w alpine rm -rf /w/node_modules
  (node_modules created by the container is root-owned).
- nginx sends Cache-Control: no-cache for the page and immutable for /assets/ -> the user's browser always
  gets the newest build (earlier the user saw an OLD cached build – that confused a whole round).
- window.confirm() is BLOCKED in the user's browser (returns false instantly). Never use confirm()/alert();
  use the in-app dialog: useStore.getState().ask(message, {ok, danger}) -> Promise<boolean>.
- Rendering is on demand (frameloop="demand"): anything animating must keep invalidating (RenderOnDemand keeps
  drawing for ACTIVE_MS=2000 ms after any input/store/paper change; glitter twinkles via a 100 ms interval).

3. DRAWING ENGINE (engine/paper.js – CardPaper)
--------------------------------------------------------------------
- Two faces: 'inside' (inside spread) and 'outside' (covers). Canvas width 1500 px, height by card ratio.
- Each face: objects (tape/stickers/text), ink (drawing), protect (sticker mask: nothing drawn there),
  compose (what the 3D card shows), glitter list, texts list, hasProtect, used.
  Ink drawn before an object is erased under it; ink composites ABOVE objects; eraser only touches ink.
- cut canvas = paper shape (opaque = paper) in INSIDE coordinates; outside face sees it mirrored (x -> w-x).
- Undo: region snapshots (ImageData of changed rect) – up to 150 steps / 450 MB; recordAll() for erase-all and
  resize; recordCut() for cuts. paper.undo(), paper.history, paper.canUndo.
- Strokes: beginStroke(face, tool, pt, opts) / addPoint (marks stale, re-rendered once per frame) / endStroke.
  Straightness 0 wobbly … 50 natural … 100 ruler. Tools: crayon (grain + multiply), marker, highlighter
  (chisel, multiply), brush (bristles), glitter (flecks + twinkle sparkles), pattern (stamped shapes), eraser.
- Pattern pen (tool 'pattern', like PENUP "Patterns"): RENDER.pattern in brushes.js resamples the stroke
  every size*gap*spacing% px and stamps a shape at each point (engine/patterns.js). 11 patterns: dots,
  bubbles, smileys, hearts, daisies, blossoms, stars, sparkles, smoke, leaves (vine, alternating sides,
  follows direction), confetti. Options in toolSettings.pattern: size (10-100, default 40), opacity,
  straight, pattern ('hearts' default), spacing (40-250 %, default 100), rainbow (hue changes along the
  stroke). It is ink: eraser removes it, it can't go over stickers, BLEND.pattern = normal. Card.jsx passes
  pattern/spacing/rainbow in the stroke opts. To add a pattern: add a STAMPS function + PATTERNS entry.
- Paint bucket: paper.fill(face, p, color, {opacity, tolerance=24}). Flood fill on flatFace(face) pixels
  starting at p: spreads over pixels whose EVERY RGB channel is within `tolerance` of the clicked colour
  (max-channel rule, so pale pastel lines still stop the paint – the first RGB-distance rule leaked through a
  light-pink line). Limits: only the clicked half of the sheet (x < w/2 or >= w/2: the fold separates the
  halves, a closed card shows one half), not over stickers (protect mask), not off the paper (alpha). Mask is
  grown 2 px (growMask) so it tucks under soft line edges. Painted on the INK layer in two parts (round 13):
  the clicked region itself with 'source-over' (ON TOP, so re-filling an already filled area replaces its
  colour – no limits on how often), and only the 2 px rim (mask minus region) with 'destination-over'
  (behind existing ink, so lines stay crisp). Eraser can remove fills. Undo via record(rect of mask).
  (Round 12 painted everything 'destination-over' -> a second fill went BEHIND the first one = invisible.)
- Objects: placeTape(face, poly, S, angle, pattern), placeSticker(face,id,x,y,size,rot), placeText(face,spec,x,y)
  (text box always fitted inside the card).
- Pending tape: setPendingTape({face,S,E,width,pattern}). Cut with scissors -> placeTape.
- Card cutting: beginCut/addCutPoint/finishCut({onlyHalf}) -> if pieces > 1 -> paper.choice (user clicks the
  piece to keep) -> chooseCutPiece; cancelChoice keeps the biggest. Scissors path over the desk is kept.
  Cuts that never touch paper do nothing (no undo step). Closed card: onlyHalf (only the layer being cut).
  Cut shadows: cutShadows() -> edge rim + 'under' shadow on the inside page when layered (card closed).
- Rendering: frame(t) redraws only dirty rects per face (markFace(face, rect)) and returns [{face, rect}];
  Card.jsx uploads only that rect to the GPU (uploadRegion, texSubImage2D). Crease line painted on screen.
- Save: serialize() -> {image (flat inside), layers {inObjects,inInk,inProtect,outObjects,outInk,outProtect,cut},
  texts}; load(design) restores; thumbnail(); flatFace(face,t) for exports; sampleColor(face,p) colour picker.
- resize(sizeId) scales everything to the new card size (undoable). eraseAll() clears both faces + cuts.

4. FEATURES IMPLEMENTED (all tested in the browser)
--------------------------------------------------------------------
DESK & TOOLS (scene/Desk.jsx)
- Tools on the left: crayon, marker, highlighter, brush, glitter gel pen (clear barrel, visible coloured gel,
  never runs out), PATTERN PEN (round 11, in the old pipette spot, home [-11.2,-0.65]), 6 washi tape rolls, scissors (red handles, like user's picture),
  eraser, sticker sheet, "Aa" text pad. DEFS array holds home positions, kind, len/width/r for footprints.
- Press on a tool = picked up instantly; keep the button down and drag onto the card to use it at once.
- Held tools are drawn exactly UNDER THE CURSOR (underCursor(): placed on the eye->cursor line), so where you
  see it is where it lands. (Lifting straight up made tools look higher than their drop point -> bug fixed.)
- Click the desk with a tool in hand -> leaves it there (spots[id] = {x,y,yaw}). Refused with a toast
  "Oops! This place is occupied by another tool…" if placeProblem() says 'tool' (gap 0.22), 'card' (margin
  0.12) or 'offscreen' (not visible / under panels – checked by projecting to screen against DOM blockers).
  Drop tries yaws [small random tilt, 0, -tilt] and uses the first that fits (random tilt made it flaky).
- "Put it back" / Esc / right-click -> putBackTool(id): home if free; else nearest free spot near home on the
  left; else mirrored place right of the card; else anywhere free (findFreeSpot rings).
- "🧹 Put all tools back" (top bar, always visible) -> store.putBackAll() -> all spots cleared, tools glide home.
- KeepToolsVisible: when the card (once settled) covers a tool, the tool moves to the nearest free visible
  spot (not on other tools). ToolItem animates any change of resting place: pens ROLL (rotation about their
  length, rolling without slipping), flat things SLIDE with ease-out (~0.65–1.6 s).
  IMPORTANT: ToolItem passes position/quaternion props only once (startPose) – otherwise React snaps tools.
- Tape rolls are clickable everywhere (invisible solid cylinder covers the hole).
- Picking tools is reliable: every long tool (DEFS entries with len) has an invisible GrabArea cylinder
  (radius = min(0.32, width/2) + 0.06) so thin pens are easy to grab; the nearest object wins. The glitter
  pen's sparkle flecks (<points>) have raycast={() => null}, and the Canvas raycaster uses
  Points/Line threshold 0.01. (Bug fixed in round 9: three.js "hits" points from up to 1 world unit away
  by default, so the glitter pen's flecks stole hover/clicks from the brush next to it.)
  RULE: any new decorative points/lines/sprites in tool models must get raycast={() => null}.
- Scissors: with pulled-out tape they ONLY cut the tape (straight line, any angle; the cut may start/end on
  the desk; a snip that touches the tape is extended across it; a snip only on the desk does nothing).
  Picked up on their own they cut the card (any shape, from the desk too).
- Tape flow: press on card + drag pulls tape; release -> roll stays at the end of the tape (doesn't move
  while scissors cut) -> scissors auto-selected -> cut -> roll + scissors go back, tool returns to tape.
- Sticker: peels off the sheet and follows the cursor; text pad stays beside the text preview.
CARD (scene/Card.jsx)
- Starts folded (front cover). Open/close by sideways drag (no tool) or buttons/O key. Works from front, back,
  any rotation: fold state store.halves = [a1,a2] (each -1/0/1, ±1 = flipped over that side); planTurn()
  always turns the layer nearest the viewer towards the viewer. cardIsOpen(halves). turnCardPage(dir).
  Buttons: "Open card" / "Close ←" / "Close →".
- Click card (no tool) = pick up; drag = turn (Shift = diagonal); click card/desk = put down (snaps flat).
  Turn card popover: 3 axes (v vertical/spin, l longitudinal, d diagonal) with sliders. store.angles.
- "🎯 Reset rotation": angles 0, not held, sheet face-up (open -> [0,0], closed -> [1,0]).
- Both sides drawable; picking colours, cutting, etc. work on whichever surface is hit.

  Click empty slot = put current colour; click filled = use it; double-click filled = replace with current

- Erase all (top bar + menu) -> in-app confirm -> clears both sides, tape, stickers, text and cuts (undoable).
- Buttons: hover = warm tint, pressed = deeper; coloured buttons (primary/danger-solid/active) darken and keep

ZOOM (scene/zoom.js, Desk.jsx SplitRenderer, ui/Zoom.jsx)
- "🔍 Zoom in" (or +) -> split screen: left = normal desk view (cropped, unchanged), right = magnified card
